# DynamicRouteLab frontend

React + TypeScript + Vite single-page app. See the top-level `README.md` for setup, development,
and deployment. In development, Vite proxies `/api` to the FastAPI server on port 8000.

```bash
npm ci
npm run dev      # development server on :5173
npm run build    # production bundle in dist/ (served by the backend)
```
